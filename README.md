# Asystent-dla-diabetyk-w-i-kontroli-glikemii
Aplikacja webowa do monitorowania poziomu cukru (pomiary punktowe i ciągłe CGM) wraz z wizualizacją na wykresach czasowych. Zawiera e-teczkę na wyniki badań (PDF), bazę wiedzy o łączeniu produktów oraz moduł rekomendacji posiłków oparty na indeksie glikemicznym.
